# Weather Dashboard

A responsive weather dashboard built with React and JavaScript using the Open-Meteo REST API.

## Features

- City weather search
- Current weather
- Feels-like temperature
- Humidity and wind speed
- Hourly forecast
- 7-day forecast
- Recent searches
- LocalStorage persistence
- Loading and error states
- Responsive design

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite
- REST API
- Open-Meteo API
- LocalStorage

- Async JavaScript
